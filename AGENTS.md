# Agent Notes

This repo contains the source for Jack Harrhy's personal website.

## Vault Content

The Markdown files under `vault/Garden` are Jack's writing. Agents may help restructure files, fix broken Markdown syntax, move pages, update frontmatter, repair links, and convert mechanical formatting from older systems.

Do not write words on Jack's behalf.

Do not rephrase, rewrite, polish, summarize, expand, or otherwise alter prose in the vault unless Jack explicitly asks for that specific text change and signs off on the proposed wording first.

When working on vault content, prefer mechanical edits:

- headings instead of accidental indentation
- lists instead of malformed task lines
- section dividers where structure is already implied
- frontmatter changes
- route/link/embed fixes
- preserving existing wording exactly where possible

If a page needs editorial work, propose the structure and identify the sections that need Jack's writing instead of drafting replacement prose.

## Code And Tooling

Code, scripts, styles, and build configuration can be edited normally to support the site.

Keep changes minimal and verify with `npm run build` when route/rendering behavior changes.
